## Design

If the active specification references a design inside the design/ folder, use that design as the visual reference.

Do not invent layouts when a design has been provided.

---

## Active Specification

Implement only the currently active specification.

Do not implement future features.

Do not expand the project scope unless the specification explicitly requires it.

---

## Conflicts

If documentation, rules, and specifications conflict:

1. Specification
2. Documentation
3. Project Rules

If the conflict cannot be resolved, stop and ask for clarification instead of making assumptions.
